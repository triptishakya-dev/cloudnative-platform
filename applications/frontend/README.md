# CloudNativ frontend

Responsive product catalog, order review/history, account sign-in, and administrator product management.

```bash
npm install
npm run dev
```

Open http://127.0.0.1:3003. The server defaults to the gateway at http://127.0.0.1:3100.
See ../../docs/frontend.md for full backend setup, account creation, administrator setup, testing,
and known limitations. Sample collection: /products?mode=preview (clearly marked, not orderable).

```bash
npm run build
npm run test:integration
```
